An Agent Should Have to Earn Every Action

Whenever someone hands an AI agent access to a live terminal, inbox, or production repository and says "we wrote a really careful system prompt," I think of the ordinary person sitting downstream when something goes sideways. Imagine opening your laptop to find a folder altered, a message sent, or a deployment rolled out, and asking two basic human questions: what exactly happened, and who gave this machine permission? You deserve an answer built on inspectable proof rather than an apology and a prayer that the model was feeling aligned that morning.

That conviction nudged me away from prompt persuasion and toward constitutional plumbing. In Security Alignment OS, I deliberately left the language model out of the loop at first so the control plane itself could stand on bare rock. Every untrusted proposal must earn its effect step by step: carrying exact-subject evidence, clearing deterministic admission, receiving a single-use kernel-bound capability, passing through an isolated capability broker process, and running inside a sandbox where any fault closes straight to freeze or rollback.

Building the control plane before inviting the mind inside

Written in Rust as a small, replayable reference kernel, the system wires together evidence review records, admission logic, single-use capabilities, consented specialist memory, a separate broker process, a sandboxed file transformation, and a transaction-bound multi-file maintenance path over immutable private generations. Even the maintenance evaluator inspects candidate patch structure inside its own isolated process without ever executing candidate code. Policy, budgets, execution, journaling, independent checking, and signed receipts compose cleanly without asking anyone to trust a sprawling monolith beyond their own policy and clock.

To test whether those walls held under pressure, we wrote 279 tests: all passing, including an adversarial runner that attacks the broker head on with path escapes, replay attempts, forged receipts, malformed child operations, and telemetry leaks. Next, we moved the suite onto a Google Confidential Space Intel TDX instance, where all 20 required scenarios passed under a signed hardware attestation verifying nonce, issuer, audience, TDX model, Secure Boot, disabled debug, Intel TCB, immutable image digest, source revision, and project identity. Newer evidence packets even bind both the broker executable digest and the per-host runner digest while keeping older packets verifiable under their original identities. Calling this a machine-attested reproduction, rather than independent replication,keeps us honest until a second, separately administered host runs the exact same check.

Three lessons carried over from compute markets

While building the HyperIntel inference-marketplace foundation in parallel, three quiet architectural lessons surfaced that turn out to matter for any agent entrusted with real work:

  1. Nonces alone do not stop races; durable compare-and-swap does. Registering an exact initial state and advancing it atomically lets genuine retries stay idempotent while rejecting any competing writer cleanly as stale.
  2. Name your crash states instead of silently resuming them. If an admission was consumed without a terminal record, failing closed and asking for a fresh authenticated nonce or human reconciliation is how you stop an agent from quietly acting twice after a hiccup.
  3. Prove narrow invariants and hash-bind them to the code. Using Z3 4.15.0, a two-candidate abstraction of our router cannot pick an ineligible offer (unsat), while a deliberately weakened copy can (sat), with the check pinned to the SHA-256 of the routing file alongside 115 passing tests (0 failed, 2 ignored). A formal proof unpinned from the file you actually run is just nostalgia.

Carrying the same grain into outcomes and operations

Once you taste fail-closed clarity at the kernel layer, you want it everywhere an automated claim touches human stakes. In HyperAI’s outcome protocol, claims about computation freeze, run through pinned validators, allow disputes, and prepare portable settlement evidence; across 16 end-to-end scenarios (9 running as one composed automated path), incomplete observations, nondeterministic replay divergence, tampered bundles, and mid-settlement crashes all refuse silent corruption, and append-only logs let corrections supersede history without erasing it. A compact fourteen-case gateway demo mirrored that shape, one benign acceptance, thirteen unsafe rejections, zero false rejections, and fourteen recomputation agreements: small enough to inspect by hand and reported strictly at that scale.

In infrastructure remediation, Orbital Mesh brings the human back into the center of the room. Telemetry signals enter, policy and quality gates weigh the candidate response, and by default the run pauses for an operator to steer before anything touches live systems. Canonical events seal into Merkle roots with per-event proofs, while live Kubernetes actions remain disabled by default behind explicit context and namespace allowlists. I deliberately avoid calling this "self-healing", keeping a real human in the steering seat is the point, not a temporary crutch.

Five unfinished seams on the table

Trusting an author who hides their weak spots is a bad habit, so I keep the open cracks of Security Alignment OS pinned right beside its passing tests: no second independently operated host has replicated the TDX run yet; persisted state sits in plaintext (so digests catch accidental corruption rather than a local adversary rewriting both file and hash); a hostile process sharing the same user ID is outside current containment; the confidential-compute runner prints its attestation token to standard output and must stay strictly inside controlled tests; and the Linux sandbox backend has only been compile-checked on x86_64.

None of this is a finished alignment solution, multi-tenant fortress, or production sign-off. It is something humbler and, I hope, more durable: the blueprint of a boundary where an agent earns each small act one receipt at a time, and where the humans affected never have to guess who held the wheel.
